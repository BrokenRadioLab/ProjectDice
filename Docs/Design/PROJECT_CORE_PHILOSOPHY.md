# PROJECT_CORE_PHILOSOPHY

## What is Project Dice?

> **Project Dice is not a character progression game.**
>
> **Project Dice is a Dice progression roguelite.**
>
> **Every run builds a Dice Deck.**
>
> **Every completed run expands the possibilities of the next Dice
> Deck.**

------------------------------------------------------------------------

# Core Identity

The player does not permanently become stronger.

The Dice becomes more customizable.

The Dice Deck is the true protagonist of progression.

------------------------------------------------------------------------

# Two Layers of Progression

## Run Progression (Temporary)

-   Dice Face replacement
-   Dice Deck evolution
-   Relics
-   Temporary Max HP increases
-   Healing
-   Battle rewards

Everything resets when the run ends.

## Meta Progression (Permanent)

-   New Face unlocks
-   New Starter Face pools
-   New Hunters
-   New Relic pools
-   New Dice Tiers

Permanent progression expands choices, not raw power.

------------------------------------------------------------------------

# Dice Philosophy

-   Physical Dice always remains D6.
-   Dice Tier unlocks additional active Face slots.
-   Locked slots are inactive and never rolled.
-   Locked slots are not Blank or Retry.
-   Only active Faces participate in the roll pool.

Example: - Wood Dice: 4 Active Faces - Iron Dice: 5 Active Faces -
Hunter Dice: 6 Active Faces

------------------------------------------------------------------------

# Dice Combat Philosophy

Every Throw always deals Base Throw Damage.

Base Throw Damage belongs to the Dice.

Base Throw Damage never belongs to the Hunter.

Face effects modify the Throw.

Face effects do not replace the Throw.

Final Throw Result is:

Base Throw Damage from Dice Tier

+

Face Effect

When the Hero throws the Dice and it hits the enemy, some damage must
always occur. Even if the resulting Face is Guard, Mend, Lightning, or any
non-damage utility Face, the enemy still receives Base Throw Damage.

The Face then adds its own effect.

Dice Tier controls two things:

-   Active Face Slot count
-   Base Throw Damage

Example:

Wood Dice:

-   4 Active Faces
-   Base Throw Damage 3

Iron Dice:

-   5 Active Faces
-   Base Throw Damage 5

Hunter Dice:

-   6 Active Faces
-   Base Throw Damage 8

These numbers are examples unless already locked elsewhere.

The Hunter never becomes stronger.

The Dice becomes stronger.

Dice Tier determines the base power of every Throw.

Faces determine how that Throw is modified.

------------------------------------------------------------------------

# Starter Face Philosophy

Each starter Face must solve a different gameplay problem.

The player should never think:

"This Face is useless."

The player should instead think:

"This Face is useful in different situations."

## Attack

Purpose:

End battles faster.

Identity:

Primary offensive modifier.

Question it answers:

"How do I defeat the enemy more quickly?"

## Guard

Purpose:

Reduce incoming danger.

Identity:

Defensive modifier.

Question it answers:

"How do I survive longer?"

Guard should never completely replace attacking.

The Throw still deals Base Throw Damage.

## Lightning

Purpose:

Increase offensive efficiency.

Identity:

Utility / secondary offense.

Lightning should not become another Attack.

It should modify combat differently from pure damage.

Current MVP single-enemy Lightning uses a deterministic damage modifier.

Future multi-enemy Lightning direction is chaining / area damage.

## Mend

Purpose:

Maintain long-term survival across the Run.

Identity:

Recovery modifier.

Mend should preserve pressure.

The Throw still damages the enemy.

Healing is an additional effect.

Every starter Face should represent a different strategic answer.

Attack

↓

Kill faster.

Guard

↓

Take less damage.

Lightning

↓

Improve offensive efficiency.

Mend

↓

Recover for future battles.

If two Faces solve the same problem, one of them is probably unnecessary.

------------------------------------------------------------------------

# Reward Philosophy

Reward Selection should answer:

"What should I replace?"

Not:

"Which useless Face should I delete?"

Every active Face must already have meaningful gameplay.

------------------------------------------------------------------------

# Player Philosophy

The Hunter is not the primary growth target.

The Dice Deck is.

The player should feel:

"My Dice became stronger."

------------------------------------------------------------------------

# Long-term Progression

Prefer: - New Faces - New Starter Pools - Dice Tier unlocks - New
Hunters - New Relic pools

Avoid: - Permanent Attack - Permanent Defense - Permanent HP - Permanent
Critical - Character level grinding

------------------------------------------------------------------------

# Future Face Philosophy

Retry is reserved as a collectible Face.

It is never used as a placeholder for inactive slots.

------------------------------------------------------------------------

# Design Rules

1.  Battle systems exist to serve Dice progression.
2.  Dice Deck always represents the current runtime build.
3.  Every active Face has value.
4.  Permanent progression unlocks possibilities, not raw power.
5.  Runtime progression resets every run.
6.  Meta progression expands strategic choices.

------------------------------------------------------------------------
